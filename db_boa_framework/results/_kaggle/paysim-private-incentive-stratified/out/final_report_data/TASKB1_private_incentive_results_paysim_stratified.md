**Headline.** ε\* is the *largest* budget at which rewards are still mis-ranked (inversion rate > 0), so **lower is better**. Moving the incentive signal off the ~114,178-dim weight channel onto an output-perturbation channel on the 3-dim contribution vector φ moves it from **ε\* ≥ 30000 (weight)** to **ε\* = 300 (output)** — a **≥100×** improvement, against the √(d/n)≈195× predicted by noise/signal ∝ k·√(dim)/ε. The negative privacy↔incentive result is thus a property of the *channel*, not of DP-plus-Shapley per se.

> ⚠ **Right-censored, so the factor is a lower bound.** The **weight** channel is still inverting at ε=30000, the largest budget swept (weight 1/100 draws, output 0/100). Its true ε\* lies beyond the grid, so the honest claim is "**at least** 100×", not an exact ratio. Extending the sweep past ε=30000 is what would turn this into a measurement.

**How many draws decide each ε\*?** ε\* is the threshold `inversion rate > 0`, so it can be set by a single inverted draw. Both ends of the ratio are checked here, at 100 draws per ε, with exact (Clopper–Pearson) 95 % intervals.

| Channel | ε\* | inversions there | rate | exact 95 % CI | verdict |
|---|---|---|---|---|---|
| weight | 30000 | 1/100 | 0.010 | 0.0003–0.0545 | ⚠ **decided by 1 draw — do not quote as a measurement** |
| output | 300 | 6/100 | 0.060 | 0.0223–0.1260 | measured |

> **What a fragile ε\* does to the ratio.** The factor is ε\*(weight)/ε\*(output), so a threshold decided by ≤5 draws at *either* end makes the whole factor fragile — not just that end. The fix is more draws at a fixed ε (`--repeats`), which is a different experiment from extending the grid (`--eps-grid`): the grid tests *further out*, the repeats test the *estimator*. Neither substitutes for the other.

**The ordering is the robust claim.** The output channel inverts no more often than the weight channel at **11/11** swept budgets. This is a *paired* comparison — `np.random.seed(3000 + rep)` is re-set before each channel, so both see the same draw in the same iteration — and it is unaffected by everything in the fragility table above, which concerns where a threshold falls, not which channel is better.

**Ground truth (ε=∞):** weights [0.863, 0.086, 0.051], tokens [17.26, 1.72, 1.02].

**Honest boundary.** (i) The privacy unit is the *released contribution statistic* (output perturbation, clip φ to L2≤C then Gaussian), decoupled from model-weight privacy which remains the separate off-by-default `use_dp` channel. (ii) At ε=1 both channels still fail (output noise/signal ≈ k·√n ≈ 8 > the inter-org gaps): the mechanism buys ~2 orders of magnitude of budget, landing honest incentives in the practical DP regime (ε≈10–50), not at ε=1. (iii) The honest ordering is the constructed ORG_LABEL_NOISE gradient (BankA→C), as in Task A — disclosed. (iv) Each condition is ONE run: the draws inside it are paired and seeded, but nothing here is a cross-condition significance test.

**Reproducibility.** Noise draws are seeded `np.random.seed(3000 + rep)` and the seed is re-set before *each* channel, so this run reproduces bitwise and a larger `--repeats` strictly **contains** the draws of a smaller one (rep 0…99 here). Grid and repeat count are stored in the JSON as `eps_grid` and `n_repeats`; censoring is stored as `epsilon_star_weight_censored` / `epsilon_star_output_censored` rather than left to be re-derived.
