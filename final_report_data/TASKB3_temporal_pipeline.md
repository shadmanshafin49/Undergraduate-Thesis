# Contribution 3 (B3) — Temporal Pipeline + Architecture

_Auto-generated by `experiments/temporal_pipeline_ablation.py`. Drafts-before-tex workflow._

**Root cause.** The shipped pipeline windows transactions *after* a random shuffle, so its sequences carry no temporal structure — which is why a plain max-pool CNN beat every temporal model. But ULB fraud is strongly time-clustered (P(fraud_{t+1}|fraud_t)≈5.9% vs 0.17% base, ≈34× lift).

**Result.** With a causal **time-ordered** pipeline (each transaction + its 9 real predecessors, temporal past→future split, no look-ahead), the dilated-conv + attention ADTCN reaches MCC **+0.4585** vs the shipped-style CNN/random **+0.7700** (Δ=-0.3115, no gain). Under the *same* time-ordered pipeline the temporal model does not beat the CNN (Δ=-0.0152).

| Architecture | Ordering | Test MCC (mean ± sd) | Prec % | Rec % |
|---|---|---|---|---|
| cnn | random-order | +0.7700 ± 0.000 | 78.1 | 76.0 |
| cnn | time-order | +0.4737 ± 0.000 | 28.6 | 78.7 |
| dilated_attn | random-order | +0.7135 ± 0.000 | 65.9 | 77.3 |
| dilated_attn | time-order | +0.4585 ± 0.000 | 28.8 | 73.3 |

**Conclusion (negative / characterisation).** On this dataset temporal complexity does not pay off: the permutation-robust per-transaction CNN on stratified data is best, and a genuinely temporal pipeline makes BOTH models markedly worse (MCC ~0.77→~0.47, precision ~78%→~29%). The reason is informative — the time-ordered model fits period-specific fraud-burst correlations that do not transfer to a future test window (no label leakage; labels are never fed, only prior transactions' features, and the past→future split blocks look-ahead). The report-faithful dilated-conv + attention ADTCN is therefore implemented and rigorously evaluated (closing the "architecture misdescribed" divergence), and the simpler CNN is retained as the deployed model on the evidence. The thesis's machine-learning contribution is the federated private-incentive mechanism (B1) and scalable attribution layer, not a new detector architecture.
