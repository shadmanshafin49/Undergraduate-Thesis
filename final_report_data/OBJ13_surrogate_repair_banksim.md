## How to read this table — one column is comparable, one is not

> ⚠ **`own best Obf2` may NOT be compared across modes.** Legacy's is a maximum over ~600 noisy draws — a best-of-N order statistic, biased *upward* by construction. Deterministic's is a maximum over candidates on one frozen draw. Averaged's is a maximum over candidates of a 3-draw mean. Putting them in one column and picking the largest would hand legacy a win it did not earn; that is exactly the artefact OBJ-13 exists to remove.

> ✅ **`yardstick` is the comparable column.** Every configuration below — searched or reference — is re-scored on one shared `averaged` objective at seed 20260904, k=7, drawn from a **row-disjoint pool** (20,001 rows, 253 fraud) that no search touched — so neither its 2,000 rows nor its draws were ever seen. A different seed on a *shared* pool would not have been enough: the subsamples would still have overlapped by chance, and a configuration that happened to fit those rows would be rewarded twice. Pre-registered: the ceiling survives `deterministic` (freezing a draw does not add fraud rows — the surrogate still holds ~30, leaving ~9 in validation, and perfectly classifying nine rows is luck) and dies under `averaged` (k=3 draws must be perfect at once). ## What is NOT established here

This script scores configurations on the **surrogate's** held-out objective, not on the test set. A yardstick win is a statement about the search, not about the detector. Carrying it to a claim about fraud-detection performance requires re-running `experiments/detector_multiseed.py` with the chosen configuration as an additional arm, at the same seeds and the same pinned thread count — which is the last unticked box in OBJ-13.
