\section*{Abstract}
The expansion of Machine Learning (ML) is driving innovation across financial services, yet traditional centralized approaches continue to face critical security, privacy, and trust challenges. Federated Learning (FL) provides a decentralized alternative but often struggles with validation overhead, adversarial threats, and the verification of local model updates. This study proposes the FL-ADTCN framework, which integrates a Hyperledger Fabric permissioned consortium blockchain with Federated Learning to strengthen security and data integrity in financial fraud detection. The framework leverages Fabric chaincode as tamper-evident Smart Contracts to automate trust and enforce incentive rules on-chain, while employing a Dynamic Butterfly-Billiards Optimization Algorithm (DB-BOA) across three distinct roles: selecting the optimal leader block, tuning ADTCN hyperparameters, and computing per-organization aggregation weights in the federated rounds. By leveraging Adaptive Deep Temporal Context Networks (ADTCN), the system captures both periodic and non-periodic temporal patterns in transaction data to deliver robust fraud detection. A token-based incentive structure rewards accurate, low-latency consensus participation and penalizes defection, promoting honest behavior across the consortium. The framework is evaluated over a three-organization (BankA, BankB, BankC) federation, demonstrating scalable and privacy-preserving financial fraud detection under realistic data heterogeneity and adversarial conditions.
